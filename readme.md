# Task Management Application

This application is a simple task management tool focused on back-end operations using Express.js and the `fs` module. It allows users to create, update, and delete tasks, which are stored in a JSON file.

- **Express.js**: Handles back-end routing and server operations.
- **File System (fs)**: Manages task data by reading from and writing to a JSON file.
- **EJS**: Renders dynamic views for a user-friendly front-end experience.

## Key Features
- **Create Tasks**: Users can easily add new tasks.
- **Update Tasks**: Modify existing tasks seamlessly.
- **Remove Tasks**: Delete tasks to maintain an organized task list.

The application emphasizes a clean architecture by separating routes, controllers, and views for improved maintainability.


> **Note**: The application is meant for testing purposes only. It is not hosted anywhere, and anyone can install it locally, modify the code, and use it as desired.
